# Project Summary
HeartSync is a web application that provides AI-driven diagnostic tools for healthcare, enabling users to input symptoms and receive AI-generated diagnoses. The platform also includes payment functionalities for premium features. It aims to enhance health-related decision-making and offers a modern, minimalist design for a seamless user experience, including tracking of payment history and subscriptions.

# Project Module Description
The application consists of several functional modules, including:
- **Diagnosis Module**: Users input symptoms to receive AI-generated diagnostic suggestions.
- **Pricing Module**: Users view pricing options and purchase premium features.
- **Confetti Interstitial**: Visual effects displaying confetti for 2 seconds after a diagnosis submission, enhancing user engagement.
- **Chatbot Module**: Interactive AI support for users seeking additional information or guidance.
- **User Profile Module**: Management of user profiles, including past diagnoses and subscription status.
- **Payment History Module**: View payment and order history, including active plans and total expenditure.
- **Diagnosis Management**: Users can delete past diagnosis records, enhancing control over their data.
- **Terms of Service Module**: Information about the terms of service, including cancellation and refund policies.
- **Privacy Policy Module**: Outlines privacy practices and data handling procedures.
- **Stripe Payment Module**: New module for handling payments through Stripe for international users and subscriptions.

# File Description Inventory
- `requirements.txt`: Manages Python dependencies for the backend, including Stripe.
- `stripe_payment.py`: Handles payment session creation and verification via Stripe API for international customers and subscription payments.
- `stripe_payments.py`: API endpoints for Stripe payment processing, including session creation and verification.
- `package.json`: Manages dependencies and scripts for the frontend application.
- `pnpm-lock.yaml`: Ensures consistent installs of dependencies across environments.
- `tailwind.config.ts`: Configuration for Tailwind CSS, including custom themes and responsive design settings.
- `BottomNav.tsx`: Navigation bar at the bottom of the application for easy access to key features.
- `Header.tsx`: Contains the logic and UI for the top header, including user authentication.
- `HeroSection.tsx`: The main hero section of the homepage showcasing the application’s purpose.
- `RelationshipSection.tsx`: Provides information on relationship-focused features.
- `SolutionSection.tsx`: Displays various solutions and user testimonials.
- `DiagnosisPage.tsx`: Logic and UI for the diagnosis submission page.
- `PricingPage.tsx`: Manages the UI and logic for displaying pricing options and handling purchases, now includes Stripe payment option.
- `ChatbotPage.tsx`: Page for user interaction with the AI chatbot.
- `MyPage.tsx`: User profile management page with the ability to delete past diagnoses.
- `PaymentHistoryPage.tsx`: Page for users to view their payment history and order details.
- `PaymentSuccessPage.tsx`: New page to handle payment success messages and navigation.
- `TermsPage.tsx`: Contains the terms of service and cancellation/refund policies.
- `PrivacyPage.tsx`: Contains the privacy policy and data handling practices.
- `todo.md`: A document for tracking tasks and future improvements for the project.

# Technology Stack
- **Frontend**: React, TypeScript
- **Backend**: Python, FastAPI
- **Package Manager**: pnpm
- **Libraries**: canvas-confetti (for confetti effects), Toss Payments SDK (for payment processing), Stripe (for international payments), Tailwind CSS (for styling)

# Usage
To set up the project, follow these steps:
1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Build the application:
   ```bash
   pnpm run build
   ```
3. Run linting to ensure code quality:
   ```bash
   pnpm run lint
   ```
